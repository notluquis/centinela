# Third-party licences

One dependency, and its licence travels inside the app rather than only being named here.

## Sparkle

[sparkle-project/Sparkle](https://github.com/sparkle-project/Sparkle), the framework that installs updates. Pinned in `Package.resolved`; the release workflow reads that pin so the tools that sign an update are the ones the app is built against.

MIT, with the Berkeley-style notice its own `LICENSE` carries. That licence asks for the notice to be included "in all copies or substantial portions of the Software", and shipping `Sparkle.framework` inside a bundle is a copy — so `make app` resolves it out of the SwiftPM artifact and puts it at `Contents/Resources/Sparkle-LICENSE.txt`. Resolved rather than vendored, because a copy pasted here would go stale on the next version bump and nobody would notice; `make app` **fails** if it cannot find it.

To read it from an installed copy:

```bash
cat /Applications/Centinela.app/Contents/Resources/Sparkle-LICENSE.txt
```

## Everything else

Nothing else is bundled. The app links Apple's frameworks, which are covered by the macOS licence, and nothing is vendored into `Sources/`. The icon is generated by `Tools/generate-icon.swift` from SF Symbols; Apple's terms allow the symbols to be used in an app's interface but not, for example, redrawn into a logo, which is why the icon composes rather than traces one.
